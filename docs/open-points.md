# Open points

Ideas and decisions that were raised but deliberately left for later. Pick
one up when it matters; nothing here is blocking.

## Manga reader

- **Navigation by OCR text box.** Panel navigation zooms through the comic
  panels found by the panel detector (speech bubbles only split very wide
  panels). A separate option could step through the page's OCR text boxes in
  reading order instead, using the boxes OCR already found, with no model
  download. Undecided whether it is wanted.
- **A separate manual OCR button.** With the recognition trigger on Manual,
  the reader's one OCR button scans the current page and can no longer hide
  the boxes; on Automatic it hides and shows them. A second button would let
  both be done in either mode. Undecided whether it is wanted.
