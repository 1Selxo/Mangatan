# Mangatan v1.2.25 (build 213)

Fix an APKBridge compatibility regression introduced in v1.2.24. Opening Mihon
sources could fail with HTTP 500 and `Unrecognized field "lang"`.

- Remove unsupported top-level `lang` and `sourceId` fields from extension
  requests. Preserve source selection through the supported bridge preferences
  context, using the real JVM source ID rather than the local database ID.
- Add manga and anime regression tests against the pinned server's strict
  `DataBody` schema, covering catalogue, details, chapters, pages, videos, and
  seasons.
- Preserve existing release notes when the build workflow uploads packages.
- Bump the iOS build number to 213.

This is an app-side fix; the pinned embedded runtime and extension server are
unchanged. Physical device verification remains necessary after installing the
new build.

Validation: all 45 Mihon and embedded-bridge tests passed, including strict
request-schema tests for both manga and anime. Static analysis of the changed
service and regression test reported zero errors; formatting and whitespace
checks passed.

Full changelog: [v1.2.24...v1.2.25](https://github.com/1Selxo/Mangatan/compare/v1.2.24...v1.2.25).
