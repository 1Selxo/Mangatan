# Mangatan v1.3.0 beta 6 (build 221)

Prerelease. Beta 6 is about speed: startup, global search and long lists,
measured on a real library of 250 Mihon sources. It also fixes a round of
bugs found by the new whole-app test suite.

- Startup: the Mihon source refresh at launch skips extensions nothing has
  changed for (a full refresh still runs once a day), so it takes a fraction
  of a second instead of 20 on a large library, and the app stays responsive
  meanwhile. It also no longer rewrites every source on each launch, and a
  repository moving an extension to a new download address no longer resets
  that extension's stored settings on every launch.
- Mihon requests: the app understands the extension handle the released
  extension server sends, so requests stop uploading the whole extension
  with every call.
- Global search: searches only the sources enabled in Browse, as Mihon does,
  and says so when every source is hidden. It opens without a pause and stays
  smooth while results come in.
- Sources load about four times faster: their stored filter and preference
  lists are kept as plain-ASCII JSON, converted once in the background after
  the first launch.
- History opens without the second-long freeze on large libraries, and dates
  are faster everywhere (chapter lists, updates, the calendar). A date a week
  back no longer reads "6 days ago" across a daylight-saving change.
- Series page: scrolling a long chapter list is smooth; long chapter titles
  pause their scrolling while the list scrolls.
- Fewer background costs: the extension update badges, the update check and
  every HTTP request read only what they need, and HTTP connections are
  reused instead of a new client per request.
- Reader: stays on the page when switching to a continuous mode or resizing
  the window, and saves the page while reading, not only on leaving.
- Library: the category tabs start at the edge, Escape ends a selection on
  desktop, the title under a cover opens the series, and a cover that fails
  to load is no longer reported as an error.
- Also fixed: tracker logins on Windows, local series whose details.json is
  written the way Mihon writes it, series without a genre list, the chapter
  header in a narrow split layout, OCR progress and undecodable pages.
- iOS: the embedded Mihon runtime v18 carries extension server v1.0.9.0.
- Extension server: pairs with M-Extension-Server v1.0.9.0, which loads
  extensions in parallel and keeps converted extensions between launches.
