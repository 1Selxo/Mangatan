# Mangatan v1.2.26 (build 214)

Performance, reliability and sync-safety release.

- Measure common flows with a perf harness and speed them up without changing
  behavior: library unread badges, global search, downloads queueing,
  extension repository refresh, backup restore, startup settings reads and the
  Chimahon pre-upload safety audit.
- Fix Chimahon sync false positives and anime duplicates, and add Chimahon 2.4
  compatibility with safer sync and restore.
- Anime: lay out seasons like Anikku and Animiru, fix YouTube timeouts and
  player robustness, and keep Jellyfin entries working when a source is renamed.
- Reader: sturdier local imports, downloads and page cropping; track the
  pointer from Flutter for novel dictionary lookups.
- Mining: dictionaries, OCR and card export now fail safely.
- Statistics: never erase history after a failed storage open.
- Categories: close the order gap when a category is deleted.
- Extensions: harden extension settings, repositories and uninstall, and manage
  the desktop extension server's lifetime.
- iOS: keep the embedded Mihon bridge from crashing the app. Bump the build
  number to 214.

## Known issues

- **Anime seasons are not fully restored by Chimahon or Anikku.** Their sync
  restorer restores each season entry with base data only, so episodes, watch
  progress, seen state, categories and tracking set on a season in Mangatan
  reach the synced backup but do not appear in those apps. This is an upstream
  bug; Chimahon-side changes still sync to Mangatan, and standalone entries
  sync both ways. Details: [Chimahon sync compatibility](https://github.com/1Selxo/Mangatan/blob/main/docs/chimahon_sync_compatibility.md#known-upstream-issues).
- **Tracking does not work on season entries yet.** Tracker linking and
  progress updates do not currently apply to anime season entries in Mangatan.
